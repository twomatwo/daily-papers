## 30 秒摘要

**Authors report.** 传统科学 Agent benchmark 往往已经提供数据、代码或一组有限的候选实验；真正的实验科学却要求系统自己设计下一步观测、消耗材料、管理条件并证伪机制。作者提出 **TwinLab-Bench**：52 项由真实物理、生命科学和工程实验记录构建的任务，覆盖 100 种以上可执行实验动作。每项任务的 TwinLab agent 依据原始实验材料和有记录依据的计算器返回观察，候选 Agent 必须在有限预算内实验、解释并提交结论。13 个测试 Agent 中，最强一个在作者设定下平均只有 **45.0 / 100**。典型失误不是缺少物理常识，而是**已经提出机制却没有安排区分性实验**。

**AI interpretation.** 这份研究尤其适合用作 AI for Science / AutoLab agent 的评测设计：科学能力不仅是生成正确结论，更是**用适当证据和资源约束把替代机制排除掉**。

**Caveat.** 这是依据实测记录、局域模型外推和独立评审构造的 **agentic digital twin**，不等于真实机器人在实体实验室操作；作者虽做了模拟保真和答案泄漏控制，但不能把其打分直接解读为真实科研能力百分数。

## Big Picture：评估实验决策，而非最终答案回忆

**已有常见评测：**问题和数据集提前给定，Agent 只需解释或写分析代码；或者只能选择事先列好的有限测量。

**TwinLab：**给出一个真实实验问题的可用仪器、样品与记录，但不告诉答案。Agent 必须构造实验请求；环境执行记录支持的操作，返回观察；Agent 可持续提出下一次验证，最后提交包含证据的结论。

> 真实实验室记录 + 校准计算器 + 隐藏真值
> ↓
> TwinLab agent：维持实验上下文/材料状态
> ↑ ↓
> 被评测 AI Scientist：提出实验 → 得到观察 → 修订假说 → 再实验
> ↓
> 最终报告与已发生实验轨迹
> ↓
> 独立评分：结论是否正确 + 是否由本轮实验支持
> ↓
> 任务得分及错误归因

## 核心设计与数学化理解

### 1. 52 项任务，100+ 种实验动作

作者使用物理、化学、湿实验生物学、材料与工程等实验室记录建立题目。每项任务都有源自**真实测量**的参考材料、同一实验室可执行的操作接口和隐藏正确答案，而不仅是理论模型的任意幻觉读数。

每项 TwinLab 实验请求会先检查真实记录；已记录的条件使用相应测量值；新但邻近的条件允许校准程序内插或文献约束的局部外推；无法支撑的条件需标明 simulation limit。环境还追踪样品是否消耗等会影响下一次实验的状态。

### 2. 任务得分不只检查结论

论文中的 scorecard 将一个关键发现拆为两类 item：

- **Conclusion**：最终结论是否与隐藏真值一致。
- **Verification**：Agent 是否确实通过本次执行获得了支持该结论的实验证据。

每题分数归一到 0–100；若任何被标记为 core 的项目未取得 full credit，作者的规则将整次 run 的得分置为零。因而「凭记忆答对」可能仍然不及格。这正是评价真实科学实验行为，而不是纯粹答题能力的关键。

一个用于**理解评分规则的示意表达（非作者另行提出的优化方程）**：

$$
S_{\mathrm{task}}=0\quad\mathrm{if\ any\ core\ item\ is\ failed}.
$$

### 3. 主要结果：45/100 与实验失败类型

作者在特定代码/工具配置下比较 13 个 Agent。报告：

- Claude Fable 5.2 平均 **45.0 / 100**；
- Claude Opus 5.5 平均 **40.2 / 100**；
- 其他指定 actor 为 5.4–31.7。

这些是作者任务分布、judge 和运行成本下的数值；**不能将不同评测的agent排行榜直接混合**。

在一个针对 Opus 5.5 的失败子集里，16 次零分运行中 **12 次归因于实验决策**：7 次直接接受某机制却没有做区分性实验，4 次根据薄弱早期证据选错步骤，1 次在验证前耗尽稀缺材料。读数/报告错误占剩余 4 次。这一结论比「Agent 一般不懂科研」具体得多。

### 4. 环境保真、记忆污染与预算

作者报告 **76%** 的返回实验结果来自原始实验记录或从同实验室数据校准的计算器；**78%** 的专家路线关键实验条件直接存在于记录中。对于实验外推条件仍存在模型假设。

他们还通过修改同一题目的隐藏实验真实状态控制记忆污染：在 10 个可判定设置中，8 个 Agent 的结论随新状态变化。无实验预算的对照没有通过任何任务；不意味着完全不存在训练数据污染，而是作者试图将信息来自任务交互和记忆回忆区分。

预算也不是唯一瓶颈。在作者统计的 21 次失败 Opus 5.5 run 中，只有 8 次用掉至少 90% 预算；对这些加倍预算后，仅 2 次转为通过。**花更多 token 或进行更多无效测试，不能代替关键的证伪性实验。**

## Authors report / AI interpretation / Caveats

### Authors report

作者发布一套由真实实验记录构建的、可提出开放实验请求的 Agent benchmark。比较各种模型执行科学实验设计的成绩，分析评分可靠性、模拟器与原记录一致性及失败原因。最强受测模型平均 45.0/100，最常见决策失误是在没有 discriminating experiment 时接受机制。

### AI interpretation

它使科研 Agent 的关键能力从「会不会产生合理 hypothesis」转向「能否设计**最快区分两个可行假说**的观测」。对应于物理实验，一个更好的 Agent 应主动设计控制变量、精确误差来源和实验干预，而不是在看见一次符合预期的曲线时就宣布机制正确。

### Caveats / Open questions

- TwinLab 基于真实记录和部分外推，不是任何输入都能返回物理上真实的实验结果；局部外推可能带来偏差。
- 评审依赖 judge 与隐藏答案定义。即使双重检查，也不能等同于独立人类实验评审的形式保证。
- 数据源来自公开科学记录，预训练记忆污染不能逻辑上彻底排除；作者通过修改隐藏真值和闭卷试探降低这种风险。
- 评分可能依赖某些特定操作接口、预算及工具调用框架；不同 Agent 比较必须统一这些条件。
- 成本、实验安全、材料消耗被部分建模，但并未将真实实验室所有物理风险和维护开销全部复现。
- 研究没有证明所有科研领域的 Agent 能力排名与此 benchmark 相同，亦不能从实验设计得分推出发现新物理机制的能力。

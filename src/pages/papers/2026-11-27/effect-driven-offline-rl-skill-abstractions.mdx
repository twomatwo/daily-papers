## 30 秒摘要

不同低层动作可以产生类似任务效果。本文将离线 action chunk 压缩为离散技能 code，训练时要求 code 和起始状态能够预测未来任务相关特征，再用闭环控制器执行该技能，高层离线 RL 学习技能选择。作者报告在 OGBench 多种模拟任务上的改进，但长程失败仍存在。

## Big picture

**AI-generated explanatory diagram — 概念机制，非原 Figure。**

~~~text
Offline trajectory:  s_t, [a_t ... a_(t+L-1)], s_(t+L)
                              |
                     encoder + quantization
                              v
                       discrete skill k
                       /              \
     s_t + k -> future feature      current s + k
                  prediction                |
                  training             controller
                                            |
                                       primitive action

High-level policy (s, goal) -> skill k -> L closed-loop steps
~~~

传统动作重建要求技能保留足够信息以还原原 action chunk。本文则让技能优先表示该动作块在起始状态下产生的任务相关效果。动作细节由低层控制器结合即时观测处理。

## 核心机制与公式

~~~text
k = phi(a_t : a_(t+L-1))
L_pred = ||x_(t+L) - psi(k, s_t)||²

L_ctrl = ||a_t - pi_A(k, s_t)||²
High-level policy: pi_Z(k | s, goal)
~~~

x 是任务相关的状态特征，不必是完整状态；导航时可使用位置。离散瓶颈采用 finite scalar quantization (FSQ)。第二阶段控制器每一步读取当前状态，同一 k 持续 L 步，不是完全开环回放。第三阶段在技能动作空间使用离线目标条件 RL。

## Authors report

30 个任务与四种方法构成的 120 项比较中，作者报告 97 项显著改善、3 项显著下降、20 项不可区分。在某些 giant navigate 设置上原始方法几乎无成功而技能方法可以获得非零甚至较高成功率。困难 giant stitch 并未被解决。

## AI interpretation / caveats

- 效果预测目标使技能成为一种近似任务相关状态转移表示，并不等于学到了精确的可组合因果模型。
- 选择 x 本身是一种 inductive bias；忽略的特征可能恰好影响风险，例如障碍物距离、接触力或物体稳定性。
- 任务成功率不是物理安全率；本文并没有验证独立动作安全审核。
- 低层闭环执行缓解了 open-loop 偏差，但预测误差、离线数据覆盖不足以及长程误差积累仍存在。
- 一个潜在研究是将安全关键状态作为辅助 effect target，联合训练概率风险预测，再以独立仿真或实机实验检验校准和误拒率。

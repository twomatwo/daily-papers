## 30-second takeaway

为什么 DPO/RLVR 把参数移动不到千分之一的相对范数，却可能显著改变 LLM 输出，而预训练期间看起来更大的权重变化，对选定语料的影响并不相称？作者提出 **leverage**：把更新方向造成的**局部输出分布 KL/Fisher 变化**与同样大小的随机方向作比。在论文评估的开放 checkpoint 与部分 prose prompt 中，pretraining 长窗口近随机基准，SFT 约 **5×**，RL-Zero/RLVR 约 **400–1,500×**，DPO 可到 **400–23,000×**。作者还发现没有 FP32 master weights 的 bf16 训练存在大量坐标量化停滞。**这些是指定权重 checkpoint 和输入分布上的几何度量，不是每个阶段对任务正确率的普适排名。** [arXiv:2610.37719v1](https://arxiv.org/html/2610.37719v1)。

## Big Picture — Euclidean distance 不等于行为距离

传统的更新统计会报告参数范数变化 $\|\Delta\|/\|\theta_0\|$，但参数方向不同、神经网络的输出敏感度不同，可能让**同样大小的参数改变**产生截然不同的 next-token 概率变化。

作者的目标不是给训练算法重新命名，而是提出一个可以跨不同阶段对照的**输出几何测量仪器**。

**AI-generated explanatory diagram — 概念对比，不是作者的实验数据图：**

~~~text
                 same ||Delta theta||
                 /                  \
    random direction            trained update
          |                           |
   small projected Fisher      high-alignment Fisher
          |                           |
    small output KL              larger output KL
                 \                  /
                  normalize by size
                         |
               ratio = update leverage
                         |
       compare stages and precision controls
~~~

几何上“更有 leverage”的方向并不意味着对人类目标或科学事实“更好”；如果沿这个方向推动错误答案，也可能很有 leverage。

## Mechanism I — 从局部 KL 到 Fisher Quadratic Form

设基准 checkpoint 的 next-token 分布为 $p_t(y)=\pi_{\theta_0}(y\mid x_t)$，logit vector 的参数方向导数为 $J_t\Delta$。对小位移 $\alpha\Delta$，局部 KL 具有如下二阶展开：

$$
D_{\rm KL}(
\pi_{\theta_0+\alpha\Delta}
\Vert\pi_{\theta_0})
\big|_t
=
\frac{\alpha^2}{2}
\operatorname{Var}_{y\sim p_t}\!\left[(J_t\Delta)_y\right]
+O(\alpha^3).
$$

因此沿方向 $\Delta$ 的 Fisher response 正比于输出 logits 扰动的**概率加权方差**，而不是 logit 的任意统一平移：softmax 对所有类别增加相同常数不敏感。

作者还按相对权重位移归一化：

$$
c(\Delta)=
\frac{\frac12\mathbb E_t\operatorname{Var}_{p_t}(J_t\Delta)}
{\left(\|\Delta\|_2/\|\theta_0\|_2\right)^2},
\qquad
\rho=\frac{c(\Delta_{\rm actual})}{c(\Delta_{\rm random})}.
$$

这里 $\rho$ 描述的是**单位欧氏更新的输出敏感性**相对随机方向提高多少；同一个真实更新在不同 checkpoint / 评价 prompt 分布下会得到不同结果。**二次型的“精确测量”指当前位置的方向曲率，不能把有限幅度的实际 KL 完全等同于二阶近似。**

## Mechanism II — 为什么训练阶段差异巨大？

作者分析公开的 OLMo-3、Tülu-3、Zephyr、OLMo-2 checkpoint 轨迹，控制更新方向、范数和参数快照，在 **部分 prose 评价分布**中报告：

| 训练阶段 | 代表性的相对随机 leverage | 解读边界 |
| --- | ---: | --- |
| Pretraining 长窗口 | 约 1 | 指定窗口与 prose anchor；不等于「预训练没有用」 |
| Supervised finetuning (SFT) | 约 5 | 与对应基准方向比较 |
| RL-Zero / RLVR | 约 400–1,500 | 特定 checkpoint/数据与目标 |
| Direct Preference Optimization (DPO) | 约 400–23,000 | 对 anchor 和训练配方非常敏感 |

“预训练窗口接近随机”应理解为**该论文测量的函数空间局部敏感度指标**，不能推广为“预训练只是噪音”或“预训练能力无价值”。在 math/code 分布、不同窗口与 checkpoint 位置可能得到不同的结果。

作者还对部分受控 SFT/DPO 训练轨迹进行重复实验，以区分对发布 checkpoint 的观察与训练配方的影响。高 leverage 也可能在训练持续进行时发生衰减，这提示局部更新的输出敏感度随位置变化。

## Mechanism III — bf16、FP32 master 与量化冻结

如果在 bf16 权重网格上直接累积很小的更新，而不保留 FP32 master copy，一次梯度步长可能低于权重舍入的分辨率，导致本该发生的移动被抹掉。

作者在指定实验中观察到 **36–99% 的权重坐标不发生可辨识更新**，并报告 leverage 最多下降约 **7 倍**。这说明测量到的模型更新方向，不只受学习算法影响，还取决于训练系统的数值实现。

不要把它误解为「bf16 训练一定不能收敛」。许多混合精度训练流程保留更高精度的主权重或优化器状态。论文警告的是**没有 FP32 master、直接舍入参数更新**的特定路径。

## Mechanism IV — DARE 为什么能用几何预测？

DARE (drop-and-rescale) 在模型差分向量中随机丢掉一部分坐标，并把保留的差分放大，以期复用训练成果。问题在于，**坐标随机掩蔽不一定沿着模型功能上无害的方向**。

作者使用 sign-flip null 的相对 Fisher 几何量 $\rho_{\rm sign}$，在二次近似可用的条件下提出相对 projected KL damage：

$$
\frac{\mathrm{damage}_{\rm DARE}}
{\mathrm{damage}_{\rm original}}
\approx\frac{1-p}{p\,\rho_{\rm sign}},
$$

其中 $p$ 是保留概率。这个关系在 DARE **实际成功的范围内**可预测损伤量级；当大扰动使局部 Fisher 稳定性假设失效时，不能认为这是一条对任意模型差分都精确成立的损伤律。

## Authors report — 作者实际建立了什么？

- 定义并测量以 Fisher quadratic form 归一化的训练更新 leverage。
- 在若干公开 checkpoint 中观察不同训练阶段的强烈差异，提供受控复现实验检查。
- 在指定的 bf16 无 FP32 master 情形中测得坐标冻结及变化的 leverage。
- 给出关于 DARE 丢弃/缩放引起的局部功能损伤的近似预测，并对实验结果核验。

## AI interpretation — 对 Physics of AI 的学习价值

如果比较 SFT、RLVR、DPO 的效果，只记录 $\|\Delta\theta\|$ 很容易误导：参数变化应同时用**输出分布变化、实际任务质量、泛化与鲁棒性**来评价。这篇的 leverage 可以作为其中的一个几何诊断量，而不是替代 reward/accuracy 的通用效能分数。

对模型合并与 agent skill updates，还应记录更新方向、anchor checkpoints、训练数值精度和实际评测 prompt 分布。一个很小的参数 patch 如果落在高 Fisher 方向，就可能明显改变输出。

## Caveats — 不应由此推断的结论

- Fisher 二次型衡量局部**函数变化**，不是奖励值、正确率或真实世界任务成功率。
- 几个 stage 的数值范围依赖模型、checkpoint、测试 prompt 与更新窗口，不是任何 LLM 都遵守的固定倍数。
- Pretraining 长窗口在 prose 上接近随机 baseline，不意味着其数学/代码能力或知识获取“来自噪声”。
- bf16 与 DARE 的现象依赖数值精度和小扰动条件，不能外推所有 mixed precision 优化器。
- 本导读核查 arXiv v1 HTML 的定义、主要图、实验控制与 limitations；没有独立复现全部训练或重算 Fisher 测量。

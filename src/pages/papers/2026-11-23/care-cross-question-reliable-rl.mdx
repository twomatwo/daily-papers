## 30 秒摘要

**Authors report.** CARE 把训练置信度的目标，从「每一道问题的置信度是否等于正确标签」，改为「在多个问题的置信度排序中，能否在错误率约束下保留尽可能多的自动回答」。在作者指定的 Math ID 评测中，5% selective risk 约束下的 coverage 从 RLCR 的 0.8% 升至 CARE 的 42.4%；HotpotQA OOD 从 12.3% 升至 23.6%。

**AI interpretation.** 这更像是训练模型何时应该答、何时应该 abstain 或 escalate，而不是直接增加所有问题的解题准确率；适合评价带有「人工接管」选项的科研 Agent 和安全控制代理。

**Caveat.** 作者报告的是特定 benchmark 和经验阈值的 risk–coverage，不是未来所有输入均满足 5% error 的形式化保证。跨数据集、不同模型规模下收益存在变化。

## Big Picture：从答对一题，到知道哪些题可以自动答

普通 pointwise confidence training 对每个 completion 独立奖励，比如输出 0.8 且答案正确时给高分；这并不直接训练多个答案之间的相对危险排序。实际应用中更需要决定一个阈值，高于它的答案自动交付，低于它的交给人类或更强模型。

## 核心机制与公式

### 1. C@r 不是准确率

对 N 条回答，令 c_i 为模型报告的 confidence，y_i 为 0/1 correctness，tau 为接收阈值。定义：

~~~latex
C(\tau)=\frac{1}{N}\sum_{i=1}^N \mathbf{1}[c_i\geq\tau]
~~~

~~~latex
R(\tau)=\frac{\sum_i(1-y_i)\mathbf{1}[c_i\geq\tau]}{\sum_i\mathbf{1}[c_i\geq\tau]}
~~~

忽略空接收集需单独约定的情况。选择性 coverage：

~~~latex
\mathrm{C@}r=\max_{\tau:R(\tau)\leq r} C(\tau)
~~~

一个模型可以 accuracy 不变，但如果它更会将错误样本排在低置信度区间，仍能大幅提高 C@5。**42.4% 指可以接收的题目比例，并非整个问题集的正确率。**

### 2. CARE 的跨题阈值奖惩

作者用当前生成的集合计算 tau-star(r)，对每个 completion 的标签 y 与 confidence c 给予奖励：

~~~latex
\mathcal{R}^{\mathrm{C@}r}
=(2y-1)\operatorname{sign}(c-\tau^\star(r))
|c-\tau^\star(r)|^p.
~~~

正确答案更希望 confidence 在可接受阈值之上；错误答案更希望在其下。若同一个 confidence 值在一个更严/更松的风险容忍度中相对阈值不同，就可能得到不同符号的奖励。多风险阈值同时训练能帮助从粗粒度排序转向可调 risk–coverage。

### 3. Diversity 与 on-policy 的折衷

单靠 threshold reward，语言模型容易把 confidence 缩在几个简单小数。作者加入 coarse-bin entropy 和 value-level uniqueness 等项，鼓励更细分的 confidence ranking。

但阈值估计本身依赖一个样本池。Table 5 显示每个 GRPO group 的 32 个 completion 不足以稳定低风险阈值；跨题 per-worker 约 384 个样本效果更佳，而滚动缓冲区 5000/10000 因为混入旧策略的离策略样本，表现不再单调改善。

## Authors report / AI interpretation / Caveats

### Authors report

CARE 通过按风险容忍度选择的跨题阈值奖励和 score diversity，显著改善了特定 Math ID、HotpotQA OOD 中低错误率下的 selective coverage；同时通常保持接近对照的 accuracy。reward pool 的大小与策略新旧程度影响效果。

### AI interpretation

这意味着一个 Agent 的「效用」可以是受约束的自动化覆盖率，而不是二元回答成功率。若允许 defer 人工或更强模型，可将选择性预测接入 coding/robotics/safety 工作流。但部署中的真实风险评估需要额外统计监测和监督机制。

### Caveats / Open questions

- 所有 C@r 均是该论文评测样本上的**经验风险**；不能无条件保证分布外未来错误率。
- 同样的置信度学习不必改善 raw problem-solving accuracy。
- 依赖可判定答案正确性/GRPO training rollout；真实开放式研究不一定有即时可靠 verifier。
- 按组计算的 reward 依赖 batch composition；在线及离线样本混合可能改变策略梯度。
- 未在真实安全关键机器人平台或自主科学 Agent 中验证部署效果。
- 不复制图、不复现实验，结论边界以原文限定为准。

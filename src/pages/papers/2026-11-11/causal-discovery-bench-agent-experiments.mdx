## 30 秒摘要

**Authors report：**作者在一个基于 structural causal model（SCM）的交互式沙箱中，让 **13 个模型**在 **3,802 次实验 episodes** 里主动购买观测或干预，找出结果变量 $Y$ 的**直接因果父节点**。作者对其中 **3,779 个带评分的 agent 轨迹**归因时，将 **94.5% 的相关错误**归入证据采集/实验设计环节，而不是拿到证据后的最终推断。提供充分的受控实验数据时，parent set 恢复从非受控的 9/15 改为 14/15。

**AI interpretation：**衡量科学 Agent 时，仅给它正确数据并问能否分析，和要求它自己决定**测什么、控制什么、何时停止**，是截然不同的测试。高分 Agent 不一定有可靠的因果证据链。

**Caveats：**所有任务在合成、已知真值的 linear SCM 环境进行，并不是 3,802 次真实机器人/物理实验；数据生成器的部分前提（例如可观察候选变量、线性结构）降低了真实实验复杂性。94.5% 说的是作者归因框架下的错误分布，不是「94.5% 的所有实验失败」。

**核查范围：**核对 arXiv v1 的全部主要章节、SCM 方法与 Fig.1–5 图注、budget / toolkit / protocol 消融及作者限制；未运行 benchmark、独立统计或复现模型对比。arXiv 页面标注首次提交 **2026-10-13**，本轮于 11-11 作为近期补漏发现，不当作 11-10 首发。

## Big Picture：从「读懂证据」到「制造可识别的证据」

传统知识问答：模型拿到观察数据、表格、论文，输出解释。真实科学探索：模型必须主动决策哪个实验值得做、是否有混杂、比较是否充分、是否需要重复实验。

**AI-generated explanatory diagram（概念流程，非原论文 Figure）：**

> 自主科学 Agent → 识别未解决的候选因果边
>
> → 决定 treatment 和 control 条件 → 购买 observations/interventions
>
> → 检查统计功效与样本量 → 更新 DAG / effect estimates
>
> → 收集冲突证据或结束并报告
>
> 错误可能发生在每个中间步骤；仅评判最终答案无法定位这些差异。

### 一个必须区别的例子：direct parent 与 ancestor

假设一个实验环境真实机制是：

$$
X \longrightarrow M \longrightarrow Y .
$$

若只对 $X$ 施加干预而让 $M$ 自由变化，$Y$ 可能会显著改变；此时我们测得 $X$ 对 $Y$ 的 **total effect**。但在这张图中，$X$ 不是 $Y$ 的直接父节点。

只有把其他关键候选变量固定在对照条件，才能判断是否存在独立的**直接作用**。这解释了为什么大量实验样本并不能替代合适的控制实验。

## 核心机制 / 公式：从线性 SCM 到可识别的对比

论文在每个有限个体 $n$ 上使用含噪声和个体差异的结构方程：

$$
V_j^n :=
\sum_{i\in \mathrm{Pa}(j)}
\bigl(a_{ij}+\delta_{ij}^n\bigr)V_i^n
+\varepsilon_j^n.
$$

这里 $\mathrm{Pa}(j)$ 是 DAG 中对该变量有**直接有向边**的父节点集合。作者将名称做匿名化，避免模型凭领域知识猜 DAG。

在理想的、其他变量固定的线性对照实验中，我们用

$$
\Delta_j(z)=
\mathbb E[Y\mid do(X_j=x+1),do(\mathbf X_{-j}=z)]
-
\mathbb E[Y\mid do(X_j=x),do(\mathbf X_{-j}=z)]
$$

估计 $X_j$ 的直接贡献（在作者的线性结构模型中对应目标变量方程中的系数）。如果不控制其他候选变量，则可能把**中介路径**造成的总变化误读为直接边。

**重要边界：**上式是用论文的假设帮助理解的理想控制对比；真实材料中并非所有变量可同时固定，潜在混杂、干预副作用与非线性相互作用会使因果辨识更难。

4. [Fig.4：预算与工具箱消融](https://arxiv.org/html/2611.09934v1)。同一组任务中增加预算 125 倍虽能使最终 accuracy 从 17% 到 78%，却没有同等增加真正的受控对照；四个基本统计工具可能比一组复杂因果工具更实用。

## 最关键的消融：失败究竟发生在哪里？

**Authors report：**

- 13 个模型、5 家供应商、3,802 个 episodes，报告 40 项指标、7 个类别。
- 在一个受控的 15-sandbox 对比中，直接提供合适的 controlled evidence：正确恢复 parent set **14/15**；同样数量的 untreated/uncontrolled treatment evidence：**9/15**。
- 在作者针对已评分轨迹的归因中，错误更常见于没有测试候选、没有固定其他变量、实验样本不具统计功效。
- 单纯增加预算和更复杂分析工具不能自动修复变量控制；明确五步程序或限制 per-call 购买规模可以诱导更多对照实验，但不一定抹平全部能力差距。

**AI interpretation：**

这对实验 AutoLab、VLA benchmark 和长期 Agent 很直接：要分别评价 **是否正确操作设备、测量是否有效、实验是否能区分竞争机制、最终结论是否被证据支持**。如果只给终局 accuracy，可能会奖励错误原因碰巧得出正确答案的系统。

**Caveats：**

- 合成 SCM 和随机变量名不等同于复杂真实物理领域知识，更没有现实仪器风险、漂移或隐含不可控自由度。
- 某些实验 15-sandbox 的样本量较小，不能过度推广百分点。
- 作者的错误归因依赖其预定义的操作指标与阈值，不是独立于评测框架的普适因果归属。
- 作者报告的统计工具效果取决于被测模型、预算与接口，不能作为对所有 Agent 的保证。
- 论文首次公开日期为 2026-10-13，并非本轮新 arXiv 提交。

## 30 秒摘要

**Authors report：**在 Qwen2.5-7B 与 Qwen3-8B-Base 上，研究者用数学任务训练 SFT 与 GRPO，再评价不只数学的域外推理。只匹配训练题目（prompts）时，RL 每题使用约 8 条 sampled rollouts，SFT 往往只看一条正确示例，比较并不完全公平。通过改变数据生成者、混合比例、匹配正确 rollout 数和最终匹配总 rollout 数，SFT 泛化得到显著改善；一些实验中可以达到甚至超过 RL 的测试成绩。

**AI interpretation：**论文并没有证明“SFT 普遍优于 RL”，而是揭示**优化算法与训练数据分布/计算量纠缠**，使很多已有“RL 擅长迁移、SFT 只会记忆”的直接比较难以解释。它是一篇后训练实验设计与公平归因的案例。

**Caveats：**作者实验主要局限于 Qwen 模型、DAPO 数学训练及所选域外基准，模型生成轨迹并非外生独立数据。SFT 在总量匹配设置下**真的对包含错误最终答案的整段轨迹应用了监督损失**，不能误写成“只训练正确答案”。作者对长尾推理方法的标注依赖另一个 LLM；浅层 Transformer 的理论结论仅适用于受控简化设定。没有独立复现。

**核查范围：**arXiv:2611.14912v1 主文 Sections 1–5、Fig.3、6、9、10 和 Appendix B/G 数据构造、错误 rollout 消融、理论假设；未启动模型训练。

## Big Picture：训练算法的差异，还是见到的数据不同？

一个常见的后训练实验是让同样基座做两个版本：SFT 看到一个 prompt 和一条正确解，RL 在同一 prompt 上生成多个答案、利用反馈再更新。之后 RL 的域外表现更好，容易被概括为“RL 学会泛化、SFT 只记答案”。

但这个设置同时改变了三个维度：**训练目标、模型看到的完整 rollout 数量、训练数据中覆盖的解题路径分布**。仅仅匹配题目数量，不能排除后两个因素。

## 核心机制一：为什么 prompt-matched 不是 data-matched？

作者用 Qwen2.5-7B 为主实验，Qwen3-8B-Base 为附录扩展，训练题来自 DAPO。GRPO 的实验设定每个训练题生成 **8 条 rollouts**；初始 SFT 数据集则按每题筛选一条正确答案。

从训练信号角度，SFT 的基本形式是对示范轨迹做 token-level negative log-likelihood：

$$
\mathcal{L}_{\mathrm{SFT}}=-\mathbb E_{(x,y)\sim D_{\mathrm{SFT}}}
\sum_{t}\log\pi_\theta(y_t\mid x,y_{<t}).
$$

而 RL 更新策略时会依赖 sampled trajectories 及其 reward/advantage（论文用 GRPO）。即使只比较相同问题集合，RL 学习过程仍暴露于更丰富的正负样本与不同的中间过程。

这一公式是**教学性 SFT 标准目标**，并非宣称它覆盖论文全部训练细节。

## 核心机制二：匹配标准怎样改变结论？

作者针对 Section 3.2 逐步测试不同数据量：

| 比较条件 | SFT 约含 prompt–rollout pairs | 你应该检查什么 |
|---|---:|---|
| 每个 solvable prompt 一条正确 rollout | 10,000 | 比只匹配原始 prompt 数更聚焦于可解题 |
| 按每题正确 rollout 数匹配 | 39,000 | SFT 泛化与 RL 的差距明显缩小 |
| 按每题全部 rollout 数匹配 | 138,000 | 包含约 98,000 条错误最终答案轨迹，SFT 达到或超过某些 RL 测试结果 |

**重要限定：**这不是证明这些错误轨迹本身一定优于正确轨迹。作者在 Appendix G.2 替换部分错误样本为新生成的独立正确轨迹后，得到相近性能；因此训练总量、多样性和中间过程可能共同发挥作用。

作者对错误轨迹做的分析是：很多轨迹虽给出错误最终答案，**中间推理步骤仍可能部分正确**。但其标注来自其他 LLM，人工复核样本也有限。

## 核心机制三：Data Source 与 Tail Methods

在 Section 3.1 的相对较小 SFT 数据设置下，作者混合两类来源：RL-tuned 同基座模型生成的正确解，与 Qwen3-14B 生成的正确解。

**Fig.3 / Table 1：**在这一设置下，70% RL-tuned + 30% Qwen3-14B 的混合获得最高平均表现。

**Fig.9：**当训练规模扩到约 138k pairs，作者比较更接近的混合比例，90% RL-tuned + 10% Qwen3-14B 成为所测选择中最优。

由此可以看到，**没有一个跨规模固定的“最优 teacher 比例”**。

作者还使用 LLM 标注每条轨迹包含哪些 solution methods。Fig.10 描述方法使用频率的长尾分布：扩充数据后，原本极少出现的方法更容易被覆盖，而部分这些方法在通用推理测试中被模型使用。**长尾覆盖增加与泛化改善相容，但不是排除所有混杂因素后的充分因果证明。**

## Authors report / AI interpretation / Caveats

### Authors report

- SFT 在域外推理上的表现明显依赖模型生成数据的来源和混合比例。
- 在作者测试的 Qwen、DAPO、数学训练/域外评测设置中，匹配正确 rollout 和总 rollout 数显著改善 SFT 泛化。
- 扩大的数据集更容易覆盖少见的推理方法；作者提供 LLM 标注和受控实验支持其重要性。
- 浅层 Transformer 的简化理论帮助解释为何有限数据会低估较稀有的有效策略。

### AI interpretation

论文价值在于改进研究方法：**“换了训练算法”不等于只换了算法。** 为判断 RL 自身有什么不可替代的好处，必须同时限定采样预算、数据质量、数据多样性和评测分布。这对于设计任何 GRPO/PPO/DPO 与 SFT 的研究对照都很重要。

### Caveats

- 不是“所有 SFT 都比 RL 好”；结论依赖具体基座、训练题、rollout 生成策略和评测。
- 总 rollout 数接近并不严格意味着训练总 FLOPs、采样时延、token 数、生成器调用成本完全匹配。
- 数据来源于训练后模型、teacher 和 rejection sampling，并非独立、无偏的真实推理策略样本。
- 错误最终答案的整个轨迹被纳入监督，并不表示任意错误语料都无害。
- LLM 生成的“方法类别”标签不等于可直接观察的计算电路；浅层理论也是受控假设结果。

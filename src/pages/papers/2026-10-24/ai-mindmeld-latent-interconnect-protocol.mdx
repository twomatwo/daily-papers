## 30-second takeaway

Scientific agents usually consume specialist-model output after it has been converted into text or numbers. This **Latent Interconnect Protocol (LIP)** instead maps frozen specialist embeddings into **selected intermediate states of a frozen LLM** via small learned connectors. The authors test **three protein and three molecular specialists** with Gemma 3 4B/12B and Kimi K2.6, including **unseen objects and new tasks** and combinations of independently connected specialists. They explicitly warn: making representations available does not guarantee that the LLM understands or uses them reliably.

## Big Picture: when tool output is a bottleneck

**Before:** a protein sequence model may encode many correlated biochemical attributes, but an LLM agent gets whatever summary the tool chooses to print. **This paper:** learned connectors deliver the specialist's *representation* directly. **Potential payoff:** multiple specialist encoders could inform one question even if an attribute was not explicitly requested. **Unresolved challenge:** the language model might misinterpret the incoming vector.

## Mechanism: a learned write into model hidden states

At a chosen prompt slot and layer, a simplified description is

```text
specialist representation z
    -> normalize / linear projection W
    -> inject/mix with LLM hidden state h at selected layer
    -> continue forward through the FROZEN LLM
```

This is a **conceptual abstraction**; for precise mixing profiles and loss functions use the original Section 2 and Methods A.4–A.6, not this schematic. The training recipe is **Align** specialist outputs to reference states, **Select** suitable injection layers using held-out supervision, then **Train** connector parameters through the frozen model's answer loss. The pretrained specialist and LLM weights stay unchanged.

The registry lets different encoders register different read/write profiles. This is **complementary to calling external tools**, not a claim that latent connectors replace explicit physical numerical calculations, provenance checks or other APIs.

## Authors report vs AI interpretation

### Authors report

The authors implement independent connectors for multiple frozen protein/molecule encoders and LLMs, with successful results for new entities and some new question types. They show that deeper-layer injection can improve performance over input-only injection, while using several injection layers gives the best average in the reported ablation. They release code and pretrained connectors.

### AI interpretation

For scientific agents, this suggests a future interface where spectroscopy embeddings, molecular simulations or microscopy feature models can be delivered to a reasoning model without first compressing everything to a fixed list of words. The most interesting capability may be **cross-model composition without jointly retraining every pair**.

### Caveats

The demonstration is **not** a generally validated protocol for all scientific instruments. It focuses on bio/molecular models and particular LLM architectures. Latent input may be hard to interpret, calibrate, audit or attach source provenance to. The authors explicitly observe that asking for a stepwise rationale can **reduce** performance on protein-property questions. Embedding transfer is not a mechanistic proof of what the LLM learned. Robust safety, uncertainty and independent scientific validation remain necessary.

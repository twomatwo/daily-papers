## Big picture

moiré materials 的结构问题有一个典型 scale mismatch：局域 stacking energetics 需要接近 DFT 的精度，但 reconstruction 会把体系推到几千、几万甚至百万原子；moiré-of-moiré 又把长度尺度推到几十纳米以上。

论文的策略是：**universal model 的化学先验 → 少量高价值 moiré DFT data 定向 fine-tune → task-specific knowledge distillation → observable-level validation → 超大尺度应用。**

**orb-v3 → MoiréMLIP teacher → MoiréMLIP-mini → reconstruction validation → 10^6 atoms → moiré-of-moiré polarization texture**

## Dataset and fine-tuning

Moiré Kaleidoscope V1.0 包含 **1,105 个 labelled configurations**：710 train + 395 test，覆盖 MoS₂、MoSe₂、MoTe₂、WS₂、WSe₂ 的 mono-/bilayers、R/H stackings 与多个 twist angles；3.48° structures 整体 hold out 作为 OOD test。

一个值得注意的设计是：learned target 主要对应 PBE contribution，而 long-range vdW-D2 correction 单独处理，避免把特定 dispersion correction 硬塞进 learned PES。

## Fig. 2 — few-shot adaptation and scaling

作者从 zero-shot orb-v3 出发，逐步增加 7.34° moiré training data，并同时测试 7.34°、5.09° 与 held-out 3.48°。

从 N=0 到 **N=8**，force RMSE 已约减半；随后近似服从

$$
\varepsilon_F \propto N^{-\alpha},\qquad \alpha\approx 0.29.
$$

完整 fine-tuning 后，作者报告 overall force RMSE **40.8 → 7.5 meV/Å**，energy RMSE **5.11 → 0.73 meV/atom**，且各 test subsets 的 force RMSE 约在 8 meV/Å 以下。

[原文 Fig. 2](https://arxiv.org/html/2610.04115v1#S3.F2)

## Fig. 3 — the most important validation lesson

作者明确指出：**小的 global force RMSE 不保证 moiré reconstruction 正确。**

对 4.41° H-type MoTe₂ 与 MoS₂，他们直接比较 relaxed geometry，沿 XX–MM–MX–XX line cut 检查 in-plane displacement 与 interlayer distance。部分 zero-shot uMLIPs 即使 global RMSE 不算离谱，仍会把 peak position、stacking contrast，甚至 MoS₂ 的 MM–MX interlayer-distance difference 定性预测错。

这给 AI for Science 一个很通用的原则：**surrogate benchmark 必须下沉到最终 scientific observable。**

[原文 Fig. 3](https://arxiv.org/html/2610.04115v1#S3.F3)

## Fig. 4 — what distillation buys

MoiréMLIP-mini 只有 **2.3M parameters**，约 teacher 的 9%，采用 direct-force、deep-narrow message-passing design；训练还加入 **21,833 个 teacher-labelled** MD / relaxation snapshots。

作者报告 mini 的 force RMSE 约比 teacher 高 20%，但 reconstruction pattern 基本保持；单张 NVIDIA H200 上，system-size ceiling 约扩大 **28×**，在约 10^4 atoms 附近推理约快 **7×**，并可把单次 inference 推到约 **10^6 atoms**。

[原文 Fig. 4](https://arxiv.org/html/2610.04115v1#S4.F4)

## Fig. 5–6 — why million atoms matter physically

最大的应用是 alternate-twist MoTe₂ trilayer：

$$
\theta_{12}=-4.15^\circ,\qquad \theta_{23}=+3.89^\circ.
$$

两个接近但不同的 moiré periodicities 形成约 **77 nm** 的 moiré-of-moiré superstructure，共 **439,473 atoms**。relaxation 后，两套 interface moiré lattices 无法处处同时 commensurate，mismatch 被集中到大尺度 domain walls；许多 moiré cells 上微小的 local displacement coherently accumulate，形成长尺度 strain / distortion，并组织出 hierarchical polarization network。

真正的 scientific payoff 因此不是“同一结果算得更大”，而是**只有长尺度 interference + relaxation 才能出现的结构层级**。

[原文 Fig. 5–6](https://arxiv.org/html/2610.04115v1#S5.F5)

## Authors report vs AI interpretation

### Authors report

作者认为 fine-tuning 解决 generic uMLIP 在 moiré reconstruction 上的 domain-shift / accuracy 问题，knowledge distillation 解决 inference scale；MoiréMLIP-mini 在保持 reconstruction accuracy 的同时把 fully atomistic simulation 推向百万原子，并用于 alternate-twist MoTe₂ trilayer 的 moiré-of-moiré reconstruction。

### AI interpretation

最值得迁移到其他 scientific-ML 项目的不是某个 architecture，而是四层验证：

**domain-specific data → OOD test → observable-level validation → new-scale scientific application**。

这比只看 leaderboard 更接近真实科研闭环。

### Caveats

- chemistry 主要覆盖少数 TMDs，不能外推成“任意二维材料都 DFT-accurate”。
- reference DFT setup 本身仍有系统误差。
- mini 是为 reconstruction / force inference 特化的 direct-force model，不等同于所有 long-time MD 都严格 energy-conserving。
- “可处理百万原子”不等于 arbitrary chemistry/configurations 都有同等精度。

## 30 秒摘要

普通 s 波母体倾向在两个子带中诱导同相配对；排斥性带间 Cooper pair scattering 则倾向反相。两种约束相互竞争，在一定参数区内产生既非同相也非反相的复数能隙，形成两个时间反演关联的解。作者用两带自洽平均场与能量比较建立这一理论机制；不是新材料实验。

## 核心机制与公式

取母体相位为零，诱导 gap 取实值。g_j = U N_j(0)，在零温常数 DOS 近似下配对响应 χ_j 约为 ln(2ω_c/|Δ_j|)。总能隙由以下线性形式的非线性自洽条件确定：

~~~text
Δ1 + g2 χ2 Δ2 = Δ1_ind
Δ2 + g1 χ1 Δ1 = Δ2_ind

非零虚部要求 g1 χ1 g2 χ2 = 1
实部相容条件 g1 χ1 = Δ2_ind / Δ1_ind
~~~

由于 χ 依赖总 gap 大小，这不是普通常系数线性方程。令 a = |Δ1|，b = g2 χ2 |Δ2|，c = |Δ1_ind|。非退化三角形条件为 |a−b| 小于 c 且 c 小于 a+b。相量构成闭合三角形时有镜像的两个解，分别对应正负相对相位。三角形退化时相位重新共线。

## Authors report

作者给出非实自洽解的存在条件，并对典型参数比较能量。相对相位集体模式在相应连续相变边界软化。现有 Al/Cd3As2 邻近器件是研究动机，而不是本文的新实验。

## AI interpretation / caveats

- 可将相位受挫视为有效三角形几何，而不必先假设非常规母体。
- TRSB 不等于拓扑超导或 Majorana 证据。零场二极管效应还需要相关空间对称性破缺。
- 计算为均匀两带平均场、零温及常数 DOS 近似；材料的空间结构、涨落与界面需另外核查。
